Privacy Policy

Parallel Chat Chrome Extension — Last updated: April 11, 2026

Overview

Parallel Chat is a Chrome extension that displays ChatGPT, Gemini, and Claude in a single window so you can send messages to all three simultaneously. Your privacy is important to us.

Parallel Chat does not collect, transmit, or share any personal data with external servers. All data stays in your browser.

Data We Store Locally

The extension stores the following data in your browser using chrome.storage.local:

  • Session URLs — the conversation URLs from each AI service, so you can resume sessions later.
  • Session names — names you assign to saved sessions.
  • UI preferences — your selected language (KO/EN), color theme (light/dark), panel layout, and control panel height.
  • Onboarding status — whether you have dismissed the first-run guide.

Data We Do NOT Collect

  • Your chat messages or conversation content
  • Your login credentials for any AI service
  • Any personally identifiable information
  • Browsing history outside of the AI services used by this extension

Third-Party Services

Parallel Chat loads the following third-party websites inside iframes to provide its functionality:

  • ChatGPT — chatgpt.com (OpenAI)
  • Gemini — gemini.google.com (Google)
  • Claude — claude.ai (Anthropic)

Each service is governed by its own privacy policy. This extension does not intercept or modify any data exchanged between you and these services, other than temporarily removing HTTP response headers that would otherwise block iframe embedding.

Permissions Used

  • storage — to save session URLs and UI preferences locally.
  • tabs — to open or focus the Parallel Chat viewer tab.
  • webNavigation — to detect URL changes inside iframes for session auto-save.
  • declarativeNetRequest — to remove X-Frame-Options and Content-Security-Policy headers from AI service responses so they can be displayed in iframes. This rule applies only to requests initiated from this extension.

Data Retention

All locally stored data persists until you remove the extension or clear browser storage. You can delete all saved sessions at any time from within the extension.

Contact
